# Tinder Logic Telegram Bot

Telegram-бот с реализованной логикой знакомств и системой подбора пользователей (matching system).

## Возможности
- Создание и редактирование профиля
- Просмотр анкет других пользователей
- Лайки / дизлайки
- Система совпадений (match)
- Навигация между анкетами
- Обработка пользовательских сценариев

## Задача проекта
Реализовать механику знакомств (аналог Tinder) внутри Telegram с акцентом на бизнес-логику и взаимодействие пользователей.

## Технологии
- Python
- python-telegram-bot
- PostgreSQL 
- FSM
- Docker

## Архитектура и инфраструктура
- Контейнеризация приложения с использованием Docker
- PostgreSQL в качестве основной базы данных
- Развёртывание через docker-compose
- Разделение логики приложения и хранения данных

## Как это работает
1. Пользователь создаёт анкету
2. Бот сохраняет данные
3. Пользователь просматривает другие анкеты
4. Ставит лайк или дизлайк
5. При взаимном лайке создаётся match

## Основная логика
- Хранение пользователей и анкет
- Фильтрация анкет
- Проверка взаимных лайков
- Создание совпадений (matching logic)

## Технические особенности
- FSM для управления диалогами
- Работа с пользовательскими состояниями
- Использование PostgreSQL позволяет масштабировать проект
- Хранение и обработка данных
- Реализация бизнес-логики matchmaking

```bash
cd Tinder-logic-bot
```
В директории проекта обязательно создать файл .env

Пример .env:
